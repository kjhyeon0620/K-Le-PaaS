## 2. 근거 유효: 보정 전후 분리 (#159)

`DiagnosisPrompt.parse()`는 입력에 없는 `cited` 위치를 버리고, 남은 라벨·근거가 없으면 보류로 바꾼다. 기존 하네스는 이 **보정 후** 결과를 채점했다. #159에서 저장된 모델 원문을 보정 없이 다시 채점했다(모델 호출 없음).

| 결과 | 모델 | 호출 | 기존 보고 "근거 유효" | 원시 무효 근거 (호출 · 위치) |

| #115 기준선 2차 | `gpt-6-luna` | 120 | 120/120 | 0 · 0 |
| #123 평가용 | `gpt-6-luna` | 117 | 표에 보고하지 않음 | 3 · 3 |

- 스펙 0152의 "세 모델 모두 입력에 없는 근거 위치를 만들지 않았다"는 **사실과 다르다**. 서버가 걸러냈기 때문에 보고값이 만점이었다.
- 구체 원인 결론은 보정 전후가 같았다(서버가 단정을 보류로 바꾼 것은 `qwen3.5:4b` 12회뿐). 따라서 #115·#152·#154의 **구체 원인 수치와 그에 따른 판단(#115 절감 후보 기각, #152 `gemma4` 통과)은 유지**된다. 바뀌는 것은 근거 인용의 해석이다.
- #100 저장 결과는 모델 원문을 저장하지 않아 다시 채점할 수 없다. #100·#104의 "근거 유효"도 보정 후 값으로 읽는다.
- 원시 "근거 일치"는 최소 충분 근거 묶음을 정한 뒤 낸다(평가 명세 단계).

## 3. 규칙 기준선과 LLM의 추가 가치 (#161)

#99 규칙 기준선(`DiagnosisEval.ruleBaseline()`)은 실패 종류에 고정 설명만 붙이고 구체 원인을 항상 비운다. "규칙 0/10"은 설계상 0이므로 LLM과의 차이를 보여 주지 않는다.

#161은 판정 가이드를 코드로 옮긴 시그니처 규칙(`SignatureRuleBaseline`, 테스트 코드, 현재 v1.2)을 만들고, 저장된 LLM 응답으로 세 정책을 비교했다.

| 개발 세트 51사례 | 결과 |
|---|---|
| 규칙 단독 | 지원 사례 48/49 MATCH, 잘못된 MATCH 0, 보류 사례 2/2 INSUFFICIENT |
| LLM이 규칙 대비 추가로 해결 | 1사례(`g1-mq-prb-proto`, 정답을 감사로 넓힌 사례) |
| 규칙 우선의 확신 오답 (LLM 단독 → 규칙 우선) | `gpt-6-luna` 1 → 0, `qwen3.8` 4 → 0, `qwen3.5:4b` 10 → 0 |
| 규칙 우선의 LLM 호출 | #99 120 → 20, #123 117 → 3 |

- #158 기계 변형 23사례에서도 규칙 v1.2와 `gpt-6-luna`는 흔들리지 않았다(규칙 v1.1은 이전 Pod 이벤트에 CONFLICT를 내서 v1.2에서 현재 대상 Pod로 한정). 이 세트는 강건성·보류 회귀 검사이고 진단 능력의 근거는 아니다.

## 6. 채택 판단: 규칙 우선 진단

- **평가 결론**: 지원 범위 6개 구체 원인에서는 규칙 우선이 LLM 단독보다 확신 오답이 적고 LLM 호출이 훨씬 적다. 이 범위에서 LLM의 추가 가치는 입증되지 않았다.
- **제품 반영: 보류.** 개발 세트는 규칙을 만들 때 본 사례이고, 모두 한 줄 시그니처로 드러나는 6개 라벨 안의 장애다. 규칙이 처음 보는 장애에서 잘못 MATCH하지 않는지, LLM이 분류 밖·증거 부족·충돌 장애에서 가치가 있는지는 이 세트로 알 수 없다.
- **반영 조건**(측정 전에 고정): 모델 점수를 보기 전에 동결한 새 평가 세트에서 ① 규칙 MATCH 경로의 확신 오답 0, ② 규칙 우선이 LLM 단독보다 확신 오답이 늘지 않음. LLM이 규칙 미해결 사례를 추가로 해결하지 못하면 LLM 경로를 기본에서 빼는 것도 검토한다. 반영은 별도 L 이슈로 한다.

## 7. 앞으로 보고할 때 지킬 것

- 근거 지표는 원시(서버 보정 전)와 보정 후를 나눠 적는다.
- 반복 호출은 독립 표본이 아니다. 신뢰구간과 비교는 사례(에피소드) 단위로 한다.
- 개발 세트 결과와 동결 평가 세트 결과를 구분해 적는다.
- 주입한 결함과 관측으로 입증되는 결론을 분리하고, 입증되지 않으면 자동 채점에서 뺀다.
